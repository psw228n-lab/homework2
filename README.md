# dominos-worldcup-landing

도미노피자 월드컵 시즌 사전예약 프로모션 랜딩페이지입니다.

HTML, CSS, JavaScript만 사용한 정적 페이지이며 별도의 빌드 과정 없이 GitHub Pages에 바로 배포할 수 있습니다.

## 실행 방법

1. 저장소를 클론합니다.
2. `index.html`을 브라우저에서 엽니다.

## GitHub Pages 배포 방법

1. GitHub 저장소를 생성합니다.
2. `index.html`, `style.css`, `script.js`, `README.md` 파일을 업로드합니다.
3. 저장소의 `Settings` → `Pages`로 이동합니다.
4. Branch를 `main`, folder를 `/root`로 설정합니다.
5. 생성된 GitHub Pages URL을 확인합니다.

## 주요 기능

- 모바일 우선 포스터형 프로모션 디자인
- 사전예약 30%, 승리 시 포장 40% 혜택 강조
- CSS 기반 축구 선수, 축구공, 경기장, 피자 일러스트
- 스크롤 등장 애니메이션 및 유의사항 아코디언
- 데스크톱에서 가운데 정렬되는 최대 480px 모바일 랜딩페이지
- 키보드 접근과 모션 감소 설정을 고려한 인터랙션
